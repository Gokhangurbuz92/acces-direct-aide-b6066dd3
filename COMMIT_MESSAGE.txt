fix(prisma): move SourceDocument model to top for proper dependency order

Fixes Vercel deployment blocker and Prisma validation error P1012.

Problem:
- SourceDocument model was defined at line 625 (end of schema)
- But referenced by Aide, Structure, Demarche, Dispositif models (lines 68-586)
- Prisma requires models to be defined BEFORE they are referenced
- This caused 4 validation errors during `prisma generate`

Solution:
- Moved SourceDocument model from line 625 to line 11
- Now defined immediately after datasource block
- All forward references now resolve correctly
